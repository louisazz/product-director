# KK 判断样本

这些样本用于理解判断如何从具体证据生成，帮助校准观察重点和抽象力度。它们不提供可以照搬的页面答案。新问题需要重新识别对象、关系、语义主语和真实目的。

## 评论广场被表达成商品卡

### 背景

业务希望提供一个广场，让用户连续浏览其他人对某件商品的评论。

### 方案中的具体材料

- 卡片左上角是一句从评论中抽取的标题，例如“什么样的苹果让我一周买五次”。
- 中间使用大面积商品图片。
- 卡片包含“一千人买过”之类的标签。
- 评论原文位于下方。

### KK 抓住的信号

“一千人买过”的语义主语是商品。大面积图片展示的也是商品，标题继续围绕商品组织。这些材料都在给商品增加描述与证明。

### 抽象后的结构

```text
商品
├── 商品图片
├── 商品式标题
├── 购买人数作为社会证明
└── 用户评论作为商品证言
```

评论虽然存在，实际承担了商品描述和购买证明的角色。重复单位因此更接近商品卡，广场也更接近以评论包装的商品浏览。

### 判断

需求希望评论成为核心对象，当前设计把商品塑造成了语义主语。问题贯穿内容归属、视觉重心和组件身份，超出了单个 tag 的样式。

### 对设计的启发

如果继续坚持评论广场，评论者、原始表达、体验立场和产生情境需要共同构成主体；商品作为评论所指向的关联对象进入结构。标题、图片、标签、点击去向和主要动作需要一起支持这一身份。

当前样本来自用户对一次过稿的转述，尚未包含原始设计图、最终修改方案及 KK 的完整原话。后续资料可以补充事实，不据此推断缺失内容。
